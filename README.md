# Spine Sprite Utilities

Godot project and Python scripts to automate the generation of spritesheets from 2D assets with Spine data.

## Spritesheet generator

Script to generate spritesheets for a set of Spine sprites in a Godot scene.

Multiple directional sprites can be included in the Godot scene. The base Godot scene contains a script to compute a maximum bounding box that fits all the animations for all directional sprites within the scene. Animation frames are generated by running the scene with Godot's MovieWriter enabled at a set frame rate. The images for each frame are then cropped according to the computed max bounding-box and stitched together into a spritesheet.

**Requirements:**
- Python 3.14
- Godot 4.7
- Spine runtime (create a `bin/` folder inside `godot-project/` and place the GDExtension there)
  - see https://en.esotericsoftware.com/spine-godot

**Setting up the Godot scene:**

1. Create a new inherited scene from the base scene: `godot-project/sprite_utility.tscn` and place it in `godot-project/scenes/`
2. Import your assets and create the directional sprites as `SpineSprite` nodes directly under the root node. Test your sprite animations using the Debug section of the inspector. For information on importing Spine data to Godot: https://en.esotericsoftware.com/spine-godot#Importing-into-Godot
3. Move the sprites somehwere inside the viewport (keeping their relative positions as desired) and adjust the viewport dimensions in the Project Settings so that there is plenty of room to fit all the animations for all the sprites. When the spritesheet generator script runs, it will compute a max bounding box to crop the images close to the minimum size anyway, so it's fine to use a larger viewport.

**Script usage:**

```
usage: generate_spritesheet.py [-h] [-o OUTPUT_DIR] [-a SPRITE ANIMATION] scene

positional arguments:
  scene                 name of Godot scene containing SpineSprites

options:
  -h, --help            show this help message and exit
  -o, --output-dir OUTPUT_DIR
                        output directory for results
  -a, --animation SPRITE ANIMATION
                        only generate spritesheet for a specific sprite and animation. specify sprite name followed
                        by animation name
```

`scene` should match the name of a `.tscn` file (without the extension) in `godot-project/scenes/`.
For example, use `scene1` if your scene file is `godot-project/scenes/scene1.tscn`.

By default, output files will be placed in a folder called `output/`, containing a json file for some metadata (`data.json`) and the following for each directional sprite and animation:

- `.png` files for spritesheets at 3 different sizes (original, half, quarter)
- `images/` subfolder containing `.png` files for each animation frame
- `.apng` for a high-quality preview and use with external tools
- `.gif` for a convenient, quick preview

If you want to generate new spritesheets after changing sprite positions or the viewport size, delete `data.json` before re-running to prompt max bounding box calculation next time the script runs.

**Usage examples:**

Generate all spritesheets for a Godot scene called `scene1`:

```
./generate_spritesheet.py scene1
```

Generate spritesheets only for a specific directional sprite and animation (e.g. Front sprite, walking animation):

> Note: `sprite` must match the `SpineSprite` node name, and `animation` must match the animation name in the Godot scene

```
./generate_spritesheet.py scene1 -a Front Walking
```

## Other scripts

Located in the `scripts/` folder, for automating other relevant tasks.

### GIF preview generator

Script to generate animated sprites overlaid onto static background, output as smaller `.gif` files for embedding onto websites.

Usage:

```
usage: preview_generator.py [-h] [-o OUTPUT_DIR] input_dir bg_path

positional arguments:
  input_dir             input directory containing original .apng files
  bg_path               path to background .png file to use

options:
  -h, --help            show this help message and exit
  -o, --output-dir OUTPUT_DIR
                        output directory for results
```

### Old Spine export JSON converter

Script to convert Spine json data exports from an unknown version of Dragonbones
to be compatible for use with the Spine runtime.

> Note: This is a one-off script but keeping it here for reference.

Usage:

```
usage: convert_spine.py [-h] [-o OUTPUT_DIR] input_file

positional arguments:
  input_file            Input Spine json export file

options:
  -h, --help            show this help message and exit
  -o, --output-dir OUTPUT_DIR
                        output directory for results
```
